# 花东 28.7 能否支持释「酒」？

**复核目标**　定位一个已有多种解释的字，看文例能把它的用义限定到什么程度。检索标识为 HYZ 28.7，可用「酉旁有三笔」辅助寻找；同一标识不预设读音。

| 项目 | 可复核的记录 |
| --- | --- |
| 定位 | Schwartz 花园庄东地译注章，花东 28.7，印刷第 107 页，注 100。单独的章节 PDF 是第 33 页。注 100 很长，位于该页下半部。[章节 DOI](https://doi.org/10.1515/9781501505294-003) |
| 所见材料 | 本例使用排印释文和注释。字形应回图核查；PDF 文本层漏掉了注中若干字形。 |
| 可作的判断 | Schwartz 将该辞中的用法解释为用酒行礼的动作。否定词后的句法位置支持动作解，这一位置本身不足以确定所记的词、读音或仪节细节。 |
| 谁已经讨论过 | 注 100 转述饶宗颐将其读为「酒」，也转述刘源认为其用义可能已扩大到一般性的致祭。两者都是前人之说；这里记录的是 Schwartz 的转述。 |
| 检验字形与用词 | 同注指出花东 53 同版有两种相关写法。找到其原图，先独立记录液体形笔画在器内还是器外，再检查两种写法各自出现的句法位置。若它们能互换，主张仅凭位置区分两个词便需要重新论证。 |
| 检验「专指酒祭」与「泛指致祭」 | 注 100 还指向花东 286.21–26。可先把同版各辞中独立写出的祭品、动作和受祭者逐项列出，再看目标字的分布。若只有把目标字预先译成「酒」才能推出用酒，该例便不能独立支持专指义。省略祭品的短辞也不能单独证明现场没有用酒。 |

**本例结论**　花东 28.7 可作为祭祀动作义的辞例。把它读作「酒」有明确的学术前例。现有材料尚不能判断「专指酒祭」和「泛指致祭」哪种解释适用于更多辞例，原拓和所引论著仍待复核。
